## Решение:
```java
import java.util.Scanner;

//TIP To <b>Run</b> code, press <shortcut actionId="Run"/> or
// click the <icon src="AllIcons.Actions.Execute"/> icon in the gutter.
public class Main {
    static void main() {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Привет, пользователь! Эта программа делает расчеты по формуле y = x^5 + ln^3(x) + √(x^3)");
        System.out.println("Введите переменную x: ");
        double x = scanner.nextDouble();
        System.out.println("Вы ввели: " + x);
        if (x <= 0) {
            System.out.println("Ошибка! Число должно быть больше 0! Прекращаю работу...");
        } else {
            double y = Math.pow(x, 5) + Math.pow(Math.log(x), 3) + Math.sqrt(Math.pow(x, 3));
            System.out.println("Итог: " + y);
        }
    }
}
```
